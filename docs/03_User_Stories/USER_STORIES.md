# User Stories — SN-ERMS

## Epic: Field autonomy

### US-FIELD-01
**As a** floor worker  
**I want** three big buttons for care, scions, and sales  
**So that** I need zero desk training.

**Acceptance:** `/field` opens; care check marks Done; scion form posts quantity; sale opens POS.

### US-VOICE-01
**As a** staff member with wet hands  
**I want** to say “আজ আমের স্টক কত”  
**So that** I hear stock without typing.

**Acceptance:** Mic → parse → spoken answer; destructive intents ask confirm.

### US-ACCESS-01
**As a** cashier blocked from Admin  
**I want** a clear “Request access” action  
**So that** I know why and can ask the admin.

## Epic: India-first money

### US-INR-01
**As an** India nursery admin  
**I want** ₹ and GST % on POS  
**So that** local tax testing works without IRP.
