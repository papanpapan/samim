# ইউজার ম্যানুয়াল (বাংলা) — ফিল্ড ও ভয়েস

১. অ্যাপ খুলে সাইন ইন করুন।  
২. বাঁদিকে **ফিল্ড হাব** চাপুন।  
৩. **আজকের পরিচর্যা** — জল/স্প্রে শেষে টিক দিন।  
৪. **নতুন কলম** — মাদার ট্যাগ, সংখ্যা, সেভ।  
৫. **দ্রুত বিক্রি** — পি ও এস খুলবে।  
৬. সবুজ মাইক = **হে সাবা**। স্টক/বিক্রি জিজ্ঞাসা; নিশ্চিতকরণ চাইলে Confirm।  
৭. ভাষা: প্রেফারেন্স → English / বাংলা। টাকা নার্সারির BDT/INR অনুযায়ী।
