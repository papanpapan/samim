# User Manual (EN) — SN-ERMS Field & Voice

1. Open https://localhost:5173 and sign in.  
2. Tap **Field Hub** in the left menu.  
3. **Today's care** — check each bed when watering/spray is done.  
4. **New scion** — scan/type mother tag, enter count, Save.  
5. **Quick counter sale** — opens POS; scan SKU, pay cash/UPI.  
6. Floating green mic = **Hey Saba**. Speak stock or sales questions. Confirm when asked.  
7. Language: Preferences → English or বাংলা. Currency follows nursery setting (BDT/INR).
