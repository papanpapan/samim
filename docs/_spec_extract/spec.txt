4.3 Non-Functional Requirements (NFR)
• NFR-SEC-01 (Security): JWT Token based authentication, Passwords hashed with bcrypt (salt factor 12), Helmet.js secure headers, Rate Limiting (max 100 requests/min per IP).
• NFR-PERF-01 (Performance): Point of Sale lookup response time < 200ms for 50,000+ plant SKU index. POS cart operation operates with local SQLite/IndexedDB fallback for offline tolerance.
• NFR-ACID-01 (Data Integrity): Shokol sale transaction, stock addition ebong mortality adjustment strictly PostgreSQL ACID transaction block-er moddhe thakbe jeno stock kokhonoi negative ba corrupt na hoy.
• NFR-COMPAT-01 (Hardware Compatibility): Standard USB/Bluetooth 2-inch & 3-inch thermal POS receipt printers (ESC/POS protocol) ebong handheld 1D/2D wireless barcode guns support korbe.

6. Agile User Stories with Acceptance Criteria
6.1 User Story 1: Mother Plant & Exotic Variety Tracking (US-MP-01)
User Story: As a Nursery Manager,
I want to register each exotic mother plant (e.g. Black Diamond Guava, Thai King Jamun) with its international origin and physical plot tag,
So that I can verify authenticity and ensure high-yield scions for seasonal propagation.
• Given an authenticated Manager on the Mother Plant screen, when they submit valid tag number 'MP-BDG-01', cultivar name, and plot 'Line 4, Tree 12', the record is saved.
• Then the system generates a unique QR metal identity card.
• When scions are cut for grafting, the available branch harvest count updates automatically.
6.2 User Story 2: Propagation Lifecycle & Mist Chamber Tracking (US-PROP-02)
User Story: As a Field Horticulturist,
I want to initiate an air-layering (guti kolom) batch of 500 cuttings and log stage movements into the mist chamber and hardening yard,
So that I can accurately calculate grafting success percentage and mortality loss.
• Given a new propagation batch linked to mother tree 'MP-BDG-01', initial count 500.
• When shifted from Mist Chamber to Hardening after 25 days, user enters 460 survived.
• Then the system records 40 plants (8%) as Mortality Loss in the financial ledger and shifts 460 plants to 'Hardening' stage.
6.3 User Story 3: Barcode/QR Scanning & High-Speed Retail POS (US-POS-03)
User Story: As a Counter Cashier,
I want to scan polybag QR stickers using a handheld wireless barcode gun,
So that I can complete customer checkout within 15 seconds without manually searching plant names.
• Given an empty POS cart, when a 2D barcode 'SKU-BDG-5X7' is scanned, the plant name, bag size, and unit price appear instantly.
• When quantity exceeds current stock, the system raises an alert 'Insufficient available stock'.
• On payment confirmation (UPI QR or Cash), receipt prints and stock deducts immediately.
6.4 User Story 4: Vermicompost Bed Monitoring & Yield (US-SOIL-04)
User Story: As an Organic Soil Manager,
I want to track raw dung intake, earthworm feeding, and curing days for vermicompost beds,
So that we maintain premium organic soil for nursery potting and commercial package sales.
• Given Bed #03 loaded with 1,200 kg cow dung and biomass on 01 July.
• When 65 days elapse, the system notifies 'Bed #03 Ready for Sieving'.
• User enters harvested yield of 750 kg; stock updates under Organic Fertilizers.

8. Complete User Manual & Standard Operating Procedures (SOP)
8.1 SOP-01: Mother Tree Registration & Scion Management
1. Log in to the application dashboard as Admin/Manager.
2. Navigate to 'Mother Plants' from the left sidebar and click 'Add New Mother Plant'.
3. Enter Variety (e.g. Red Diamond Guava), Tag Number (e.g. MP-RDG-01), Source Country (Thailand), Planting Date, and Plot Location (Plot B, Line 2).
4. Click 'Save & Generate Tag'. Print the metal durable tag and affix it to the mother tree.
5. When harvesting scions for grafting, click 'Log Scion Cutting', enter the quantity of stems harvested, and select the intended propagation batch.
8.2 SOP-02: Propagation Batch Creation to Ready-for-Sale
1. Navigate to 'Propagation Hub' -> 'Create New Batch'.
2. Select Mother Tree ID, Propagation Method (Air Layering / Softwood Grafting), Initial Cutting Count (e.g., 500 plants), and Stem Media (Cocopeat + Vermicompost).
3. Click 'Start Batch'. Batch status becomes 'INITIATED'.
4. After root emergence (approx 21-25 days), open batch and click 'Shift to Mist Chamber'. Record survival count (e.g., 470 plants). 30 plants recorded as Initial Mortality.
5. After 15 days of controlled humidity misting, click 'Move to Hardening Shade Net Yard'.
6. Once plants are fully established in polybags and ready for buyers, click 'Mark Ready for Sale'. System prompts for Bag Size, Cost Price, and Selling Price. Available quantity automatically increments in main stock.
8.3 SOP-03: Printing Thermal Barcode & QR Labels
1. Go to 'Plant Inventory' screen.
2. Click the 'Barcode/QR' icon next to any ready plant record.
3. Select label size: Standard 50mm x 25mm Thermal Sticker.
4. Preview shows: Saba Nursery Logo, Plant Name, Bag Size, SKU Barcode, and MRP.
5. Click 'Print' to send directly to the thermal sticker printer via ESC/POS.
8.4 SOP-04: High-Speed POS Counter Checkout & Invoicing
1. Open 'Sales POS' from navigation (Hot key: F2).
2. Point handheld barcode scanner gun at the plant polybag sticker. Item is immediately added to cart.
3. To apply bulk pricing for commercial orchardists, change Channel dropdown from 'Retail Counter' to 'Wholesale Orchardist'. Tiered discount applies automatically.
4. Enter customer phone number and select Payment Mode: Cash, UPI (Dynamic QR displayed on screen), or Bank NEFT.
5. Click 'Complete Sale & Print' (Hot key: Enter). Invoice prints on 3-inch thermal roll or A4 format, and inventory stock deducts instantly.
8.5 SOP-05: Vermicompost Bed Monitoring & Packing
1. Navigate to 'Organic Inputs & Soil' -> 'Vermicompost Beds'.
2. Click 'Register New Bed', enter Bed ID (V-BED-04), input weight of cow dung (1,000 kg), raw biomass (300 kg), and inoculation date.
3. Monitor bi-weekly moisture check alerts on the dashboard.
4. On day 65, when decomposition completes, click 'Harvest Bed'. Enter final sieved yield (e.g., 720 kg Grade-A compost).
5. Select allocation: 'Internal Nursery Potting' or 'Retail Polybag Packets'.
9. Technical Architecture, Security & Production Deployment
System-ti commercial nursery scale-e chalate nicher industrial configurations finalize kora hoyeche:
• Containerization: Dockerfile ebong docker-compose.yml file backend service, PostgreSQL database, ebong Redis cache layer-ke standardize kore.
• Database Resiliency: PostgreSQL connection pooling (pgBouncer), nightly encrypted backup dump cron job running at 02:00 AM IST.
• Zero Downtime Deployments: PM2 cluster mode (running 4 worker processes across available CPU cores) ba AWS ECS / DigitalOcean Kubernetes.
• API Gateway & Security: NGINX reverse proxy with SSL termination (Let's Encrypt Certbot), CORS strict origin validation, ebong automated SQL injection prevention via Prisma parameterized queries.
