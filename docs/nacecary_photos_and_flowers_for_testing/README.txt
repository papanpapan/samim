SN-ERMS demo media kit
======================
Path: docs/nacecary_photos_and_flowers_for_testing

Use these folder-wise photos + short videos when demoing uploads.

FOLDERS
-------
01_fruits            Fruit / produce photos + fruit_demo.mp4
02_flowers           Flower photos + flower_demo.mp4
03_indoor_plants     Indoor / houseplant photos + indoor_demo.mp4
04_outdoor_plants    Outdoor nursery / garden + outdoor_demo.mp4
05_mother_plants     Mother Plants page (+ mother_demo.mp4)
06_propagation       Propagation Hub (+ batch_demo.mp4)
07_inventory_stock   Inventory / stock (+ stock_demo.mp4)
08_pos_marketing     POS marketing media (+ promo_demo.mp4)
09_alerts_danger     Danger alerts evidence (+ intrusion_demo.mp4)
10_plant_id_leaves   Identify plant (leaf close-ups)
11_vermicompost      Vermicompost (+ compost_demo.mp4)
12_care_field        Care tasks (+ care_demo.mp4)
13_live_camera       Live camera scenes (+ live_demo.mp4)
14_videos            Master copies of all demo clips

HOW TO DEMO
-----------
1. Open the feature screen in SN-ERMS.
2. Pick a photo (.jpg) from the matching folder.
3. For video upload fields, use the *_demo.mp4 in that folder
   (or any file from 14_videos).

Sources: Unsplash (photos), MDN / W3Schools CC0 samples (videos).
Local demo/testing only — use your own nursery media in production.

Re-download script: docs/download-demo-media.ps1 and docs/fill-demo-media.ps1
